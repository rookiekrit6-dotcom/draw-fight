วิธีทำม็อด วาดแล้วสู้

ม็อดคือไฟล์ข้อความรูปแบบ JSON นามสกุล .dfmod ใช้เพิ่มสกิล อาชีพลับ และออร่าให้เกม ม็อดเป็นข้อมูลล้วน ไม่มีโค้ด ผู้เล่นจึงติดตั้งได้อย่างปลอดภัย

วิธีที่เร็วที่สุด: ในเกมกด ม็อด → โหลดม็อดตัวอย่าง แล้วเปิดไฟล์ด้วยโปรแกรมแก้ข้อความ (Notepad หรือ VS Code) แก้ตามตารางด้านล่าง บันทึก แล้วกด นำเข้าไฟล์ม็อด
โมเดล 3 มิติ (.glb) ใช้กับ เวอร์ชัน 3D บนเว็บ ซึ่งใส่กระดูกให้อัตโนมัติ และส่งออกสกิลเป็นไฟล์ .dfskill ที่นำมาใช้ในเวอร์ชัน 2D ได้

โครงไฟล์

{
 "format": "dfmod", "v": 1,
 "name": "ชื่อม็อด", "author": "ชื่อคนทำ", "desc": "คำอธิบาย",
 "skills":  [ ...สกิล สูงสุด 30... ],
 "classes": [ ...อาชีพลับ สูงสุด 100... ],
 "auras":   [ ...ออร่า สูงสุด 50... ]
}

สกิล

{ "format":"dfskill", "name":"ลูกไฟพัด", "desc":"ยิงลูกไฟห้าลูก", "color":"#ff7a2e", "cd":5,
  "steps":[ {"at":0, "do":"shot", "n":5, "spread":22, "speed":13, "dmg":7} ],
  "images":{ "boom":"data:image/png;base64,..." }, "icon":"data:image/png;base64,..." }

สกิลหนึ่งอันคือรายการ ขั้นตอน (steps) แต่ละขั้นมี at = กี่วินาทีหลังกด (0–6) และ do = ทำอะไร
หน่วยระยะ: 1 หน่วย ≈ ครึ่งความสูงตัวละคร · dmg 10 = แรงเท่าตีปกติ 1 ครั้ง · คูลดาวน์จริงจะถูกปรับขึ้นอัตโนมัติถ้าสกิลแรงเกิน (สูงสุด 60 วินาที)

ตำแหน่ง: where = self (ตัวเอง) / front (ข้างหน้า ระยะ dist) / target (ศัตรูใกล้สุด) · y = ความสูงจากพื้น

doทำอะไรค่าที่ใช้
shotยิงกระสุนn, spread (องศา), speed, dmg, pierce (ทะลุ), home (ไล่ตาม), gap, life
orbลูกพลังไล่ล่าเหมือน shot
areaดาเมจเป็นวงwhere, r, dmg, kb (แรงผลัก), launch (ดีดลอย)
fallของตกจากฟ้าwhere, r (พื้นที่), n, gap, dmg, size
beamลำแสงยิงตรงlen, w, dmg, ticks, dur
pillarเสาพลังพุ่งจากพื้นwhere, w, h, r, dmg, dur
portalประตูมิติดูดและกัดwhere, size, r, pull, dmg, dur
dashพุ่งไปข้างหน้าdist, dmg (ถ้ามีจะชนศัตรูระหว่างทาง)
blinkวาร์ปไปหลังศัตรูrange, dist
healฟื้นเลือดamt (% ของเลือดสูงสุด, สูงสุด 50)
buffบัฟตัวเองkind = rage / haste / barrier / shield / inv, dur
stunทำให้มึนwhere, r, dur (สูงสุด 2.5)
pullดึงศัตรูเข้าหาจุดwhere, r, amt (0–1)
burstอนุภาค (ภาพอย่างเดียว)where, n, speed, up, grav, life, size, rad, color, color2
ring / circleวงแสง / วงเวท (ภาพ)where, r, dur, color
spriteเล่นภาพสไปรต์img (ชื่อใน images), cols, rows, fps, size, where
shakeจอสั่นamt (0–1)
soundเสียงสังเคราะห์f, f2, dur, wave = sine / square / sawtooth / triangle

ทุกขั้นใส่ color เองได้ (เช่น "#7fd1ff") ถ้าไม่ใส่จะใช้สีของสกิล รูปใน images ใส่ได้ 4 รูป แต่ละรูปไม่เกิน 1.5 MB

ออร่า

{ "id":"aurora", "name":"แสงเหนือ", "chance":500, "hp":0.04, "dmg":0.04, "spd":0.02,
  "c1":"#3cffb4", "c2":"#7f5cff", "desc":"ม่านแสงพลิ้วรอบตัว" }

chance 500 = โอกาส 1 ใน 500 ต่อการหมุน · โบนัสค่าพลังสูงสุด hp/dmg 0.5, spd 0.3

แพ็กตัวละคร (โมเดล + กระดูก + ท่า + เสียงของคุณเอง)

แพ็กคือไฟล์ .zip ไฟล์เดียว เกมเปิดไฟล์ข้างในตามต้นฉบับ ไม่แปลง ไม่บีบ ไม่แก้ไข ใช้ได้ทั้งเวอร์ชัน 3D และ 2D

วิธีง่ายที่สุด: เปิด หน้าสร้างแพ็ก แล้วทำ 3 ขั้น: 1) ลากไฟล์โมเดล .glb มาวาง (ท่าแยกหลายไฟล์ก็ลากมาพร้อมกันได้) 2) ใส่เสียง จะเลือกไฟล์ อัดจากไมค์ หรือลากมาวางก็ได้ และกดฟังได้ทุกช่อง 3) ตั้งชื่อแล้วกด "บันทึกแพ็ก" เกมจะถ่ายภาพตัวละครสำหรับ 2D ให้เอง จากนั้นกด "เปิดหน้าส่งผลงาน" แล้วแนบไฟล์ .zip (ฟอร์มของ Google ต้องล็อกอินบัญชี Google ก่อนแนบไฟล์)

ยังไม่มีโมเดล? สร้างฟรีที่ meshy.ai แล้วใช้เมนู Animate ใส่กระดูกและท่า จากนั้นดาวน์โหลดเป็น GLB

  • กระดูกและท่าเคลื่อนไหว: ถ้าไฟล์ .glb มีกระดูก (skin) และท่า (animation) ของตัวเอง เกมใช้ของไฟล์ตรงๆ ไม่มีก็ใส่กระดูกให้อัตโนมัติ เกมจับคู่ท่าจากชื่อ เช่น Idle, Walk/Run, Attack/Punch, Cast/Spell, Hit/Hurt, Death หรือเลือกเองใน pack.json / หน้าโมเดลในเกม รองรับกระดูกได้ประมาณ 128 ชิ้นบนคอมทั่วไป
  • เสียง: wav mp3 ogg m4a flac webm opus ช่อง swing (ตอนตี) hit (ตีโดน) hurt (โดนตี) die (แพ้) ult (ท่าไม้ตายช่อง 10) และตั้งชื่อเสียงเองได้ แต่ละเสียงเล่นได้ยาวสุด 8 วินาที
  • สกิล: ใส่สกิลแบบ .dfskill ได้ 10 ท่า ถ้าอยากให้สกิลเล่นเสียงของคุณ ใช้ขั้น {"do":"sfx","name":"ชื่อเสียง"}
  • ภาพ 2D: ใส่ sprite เป็น png พื้นใส (ถ้าไม่ใส่ ตอนขึ้นคลังเราจะทำภาพจากโมเดลให้)
  • ท่าแยกไฟล์: ใส่ไฟล์ .glb ท่าละไฟล์ได้ใน animations (ต้องใช้โครงกระดูกชื่อเดียวกับโมเดลหลัก) ถ้าไม่มี pack.json เกมถือว่า .glb ไฟล์อื่นในแพ็กเป็นไฟล์ท่า
  • ขนาดแพ็กรวมไม่เกิน 80 MB ไม่เกิน 64 ไฟล์

สตูดิโอสร้างเอฟเฟกต์สกิล

เปิด สตูดิโอเอฟเฟกต์ เพื่อวาดภาพเอฟเฟกต์เอง ทำหลายเฟรมให้ขยับ วาดเส้นทาง และวางลำดับบนไทม์ไลน์ บันทึกเป็นไฟล์ .dfvfx หรืออัดเป็นวิดีโอได้

ใช้เป็นสกิลในเกม 3D: ในหน้าเลเยอร์ของสตูดิโอมีกล่อง "ใช้เป็นสกิลในเกม 3D" ตั้งชื่อ จุดเกิด (หน้าตัวละคร ที่ตัวเอง หรือที่ศัตรู) ระยะ ขนาด คูลดาวน์ แล้วกด "ใส่ในเกม 3D" สกิลจะเข้าไปอยู่ในช่องที่เลือกทันที ดาเมจตั้งได้ทีละเลเยอร์ ("ทำดาเมจเมื่อใช้ในเกม") และจะโดนตอนเลเยอร์นั้นเริ่ม ในเกม จุดกลางของฉากคือจุดที่สกิลเกิด และทิศเข้าไปในจอ (−Z) คือทิศที่ตัวละครหัน ไฟล์สกิลแบบนี้ใส่ในแพ็กตัวละครได้ด้วย

ผลต่อศัตรู (ใส่ในไฟล์ได้เลย เกมอ่านเอง): แต่ละเลเยอร์ใน fx.layers ใส่ค่าเหล่านี้ได้ hitDmg ดาเมจตอนเลเยอร์เริ่ม (0–200) · hitR รัศมี · ccStun สตัน วินาที (0–3) · ccRoot ตรึงกับที่ (0–4) · ccLift กระแทกลอย (0–12) · ccSlow ทำให้ช้าตลอดช่วงที่ปล่อย (0–0.9) · ccPull ดูดเข้า/ผลักออก (−8 ถึง 8) · tickDmg + tickEvery ดาเมจต่อเนื่อง · snd เสียง เช่น "b:boom" ค่าที่เกินช่วงจะถูกปรับให้อยู่ในช่วงเอง บอสโดนสตันและช้าแค่ครึ่งเดียว และสตันซ้ำติดๆ กันจะสั้นลง ยิ่งใส่ผลแรง คูลดาวน์ยิ่งนาน ศัตรูที่โดนสตัน ตรึง หรือลอยอยู่ จะโดนดาเมจแรงขึ้น 30%

ค่าระดับสกิล (ใหม่): "el" ธาตุของสกิล ใส่ได้ fire ไฟ, ice น้ำแข็ง, thunder สายฟ้า, wind ลม, void ความมืด (ไม่ใส่ เกมเดาจากชื่อและสี) ธาตุต่างกันโดนศัตรูตัวเดียวกันภายใน 4 วินาทีจะเกิดคอมโบธาตุ เช่น ไฟ+ลม = พายุเพลิง, น้ำแข็ง+สายฟ้า = ช็อตเยือกแข็ง, ความมืด+อะไรก็ได้ = ระเบิดสุญญากาศ · ในขั้น vfx ใส่ "track": 3 ให้เอฟเฟกต์เคลื่อนตามศัตรูที่ใกล้ที่สุด (ความเร็ว 0.5–12) · สกิลจากสตูดิโอใช้ได้ทั้งเกม 3D และเกม 2D

แชร์ม็อด

ส่งไฟล์ .dfmod ให้เพื่อนได้เลย (ไม่เกิน 3 MB) ม็อดเก็บอยู่ในเบราว์เซอร์ของแต่ละคน ถ้าสู้ออนไลน์ ทั้งสองฝ่ายต้องติดตั้งม็อดเดียวกันถึงจะเห็นสกิลจากม็อด
