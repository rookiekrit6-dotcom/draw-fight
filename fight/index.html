ปุ่มกด (คีย์บอร์ด)

A / Dเดิน · ชิดกำแพงตอนลอย = ไถลกำแพง
W / Spaceกระโดด (ค้าง = สูง) · กลางอากาศ = กระโดด 2 ชั้น · ติดกำแพง = ถีบกำแพง
Shiftพุ่ง (บนพื้น/กลางอากาศ) · S + Shift = กลิ้งหลบ
Lกัน · กดพอดีก่อนโดน = ปัดป้อง
U / Iจับทุ่ม (ถอยค้าง = ทุ่มหลัง) / ท่าไม้ตาย (เกจเต็ม)
บนพื้น
J J J Jหมัด → หมัดตรง → หมัดเหวี่ยง → เตะกวาด
ถอย + Jหมัดหมุนหลัง (ต่อคอมโบได้)
S + Jอัปเปอร์คัตงัดลอย → กด W ทันทีกระโดดตาม
Kเตะหมุน (ค้าง = ชาร์จ)
เดินหน้า + Kถีบยันชนกำแพง
S + Kกวาดขาล้ม → กด W กระโดดตามได้
วิ่ง/พุ่ง + J / Kเข่าลอย / พุ่งชนไหล่
กลางอากาศ
J J Jหมัด → หมัด → เตะ
W + J / S + Jอัปเปอร์คัตลอยขึ้น / ทุบลงพื้น (เด้ง)
Kเตะพุ่งเฉียงลง (เด้งพื้น)
ตีโดนแล้ว W / Shiftกระโดดหรือพุ่งต่อคอมโบได้ อย่างละ 1 ครั้ง
J / K ตอนเกาะกำแพงดีดตัวเตะออกจากกำแพง
เคลื่อนที่พิเศษ
วิ่ง + Sสไลด์ลอดใต้การโจมตี · ระหว่างสไลด์กด J/K = เตะงัดขึ้น
กลางอากาศ S + Kกระแทกพื้น ลงพื้นแล้วเกิดคลื่นกระแทกงัดศัตรูที่ยืนใกล้
ตกผ่านขอบแท่นเกาะขอบอัตโนมัติ · W = ปีนขึ้น · S = ปล่อย · J/K = ปีนพร้อมเตะ
บนแท่น S + Wทิ้งตัวลงผ่านแท่น
ปิดฉาก
K ตอนคอมโบ 5+ ฮิตเตะจามปิดฉาก (สโลว์)
อาวุธ (เมนู ☰ → อาวุธ): ปุ่มเดิมทั้งหมด แต่ท่าเปลี่ยนตามอาวุธ · ดาบ เร็วสมดุล · หอก ยาวที่สุดในแนวตรง · ค้อน ช้าแต่หนัก ฟาดพื้นเกิดคลื่นกระแทก · แส้ ไกลสุด ปลายแส้แรง +30% · โล่ ดันแรง และรับดาเมจด้านหน้าลด 32% · ธนู เล็งเอง · คทาเวท ลูกพลังไล่ตาม หนัก = อุกกาบาต, S+J = เสาหินงัดใต้เท้า · ระเบิด โยนโค้ง, S+J = วางกับระเบิด · มีดบิน ขว้างเร็วระยะสั้น · จักร ขว้างแล้ววนกลับ หนัก = หมุนค้าง · ปัดป้องกระสุนพอดี = สะท้อนกลับ
