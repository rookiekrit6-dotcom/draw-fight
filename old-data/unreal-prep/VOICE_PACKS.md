# เสียงพากย์ที่ผู้เล่นอัดเอง (Voice Packs)

## ผู้เล่นทำยังไง
1. เปิดหน้าอัดเสียง: https://rookiekrit6-dotcom.github.io/draw-fight/voice/
2. ตั้งชื่อแพ็ก เลือกตัวละคร กด ● อัด ทีละประโยค (พิมพ์ซับไตเติ้ลได้) → ดาวน์โหลด .zip
3. ในเกม: เลือกตัวละคร → "เปิดโฟลเดอร์เสียง" → แตก zip วางโฟลเดอร์ลงไป → "โหลดใหม่"
4. กดปุ่มชื่อแพ็กเพื่อสลับเสียงของตัวละครนั้น (มีเสียงตัวอย่างดังให้ฟังทันที)

หรือใช้โปรแกรมอัดเสียงอะไรก็ได้ (Audacity ฯลฯ) ขอแค่ส่งออกเป็น **WAV 16-bit** ไม่เกิน 12 วินาทีต่อไฟล์ แล้วเขียน voice.json เอง

## โครงสร้างแพ็ก
```
VoicePacks/
  เสียงพี่เพลิง/
    voice.json
    ultimate_1.wav
    win_1.wav ...
```
```json
{
  "format": "dfvoice",
  "name": "เสียงพี่เพลิง",
  "author": "YEDHEESLAYER",
  "character": "blaze",
  "lines": {
    "ultimate": [ { "file": "ultimate_1.wav", "text": "จงมอดไหม้!" } ],
    "win": [ "win_1.wav" ]
  }
}
```

## เหตุการณ์ที่มีเสียงได้ (สุ่ม 1 ประโยคจากที่อัดไว้)
| key | เมื่อไหร่ | โอกาสพูด / เว้นช่วง |
|---|---|---|
| select | ถูกเลือกในเมนู | ทุกครั้ง |
| fightstart | เริ่มสู้ | ทุกครั้ง |
| attack | ตี | 15% · เว้น 6 วิ |
| skill | ใช้สกิล | 60% · เว้น 2 วิ |
| ultimate | ท่าไม้ตาย R | ทุกครั้ง |
| hurt | โดนตี | 35% · เว้น 4 วิ |
| lowhp | เลือดต่ำกว่า 25% | ครั้งเดียวต่อรอบ |
| dash | หลบ | 25% · เว้น 5 วิ |
| kill | ล้มศัตรู | 30% · เว้น 3 วิ |
| bossappear | บอสโผล่ | ทุกครั้ง |
| win / lose | จบรอบ | ทุกครั้ง |
| rareaura | หมุนได้ออร่า 1 ใน 1,000 ขึ้นไป | ทุกครั้ง |

ประโยคธรรมดาจะไม่พูดทับกัน ส่วน ultimate / win / lose / bossappear / rareaura / select พูดแทรกได้

## ในโค้ด
- `DFVoiceSubsystem` สแกน `Saved/VoicePacks` ตอนเปิดเกม อ่าน WAV เองไม่ต้องใช้ปลั๊กอิน (16-bit PCM โมโน/สเตอริโอ)
- ระบบสกิลเรียก `UDFVoiceSubsystem::Get(this)->Play(this, Hero, EDFVoiceEvent::Skill)` ตอนร่ายสกิล (ยังต้องต่อกับระบบรันสกิล F1)

## ต่อยอดภายหลัง
- อัดเสียงในเกมได้เลย (UE AudioCapture) ไม่ต้องออกไปหน้าเว็บ
- แชร์แพ็กผ่าน Steam Workshop + ปุ่มรายงานเสียงไม่เหมาะสม
- รองรับ .ogg/.mp3 ด้วยปลั๊กอิน RuntimeAudioImporter (ฟรี)
