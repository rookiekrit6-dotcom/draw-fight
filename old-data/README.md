| โฟลเดอร์ | คืออะไร |
|---|---|
| 3d/ | โมเดล 3D (.glb) และภาพตัวละครของเกมเก่า |
| mods/ | ไฟล์ม็อดและสกิล (.dfmod / .dfskill) |
| unreal-prep/ | ข้อมูลสกิลและโค้ดเตรียมย้ายไป Unreal |

Data kept from the old draw-and-fight game. Its code is gone from this tree; `git checkout old-draw-fight-final` brings the whole old site back.
