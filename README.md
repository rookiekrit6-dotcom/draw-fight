# วาดแล้วสู้ (Draw Fight)

เกมบนเว็บ วาดหรือนำเข้าตัวละครและอาวุธของตัวเอง แล้วเอามาสู้กัน สกิลและค่าพลังมาจากสิ่งที่วาด

เล่นได้ที่ https://rookiekrit6-dotcom.github.io/draw-fight/

ข้อมูลผู้เล่นเก็บในเบราว์เซอร์ของแต่ละเครื่อง

สงวนลิขสิทธิ์ทั้งหมด ดูไฟล์ `LICENSE` ห้ามคัดลอกหรือนำไปเผยแพร่ซ้ำโดยไม่ได้รับอนุญาต
