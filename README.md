# เว็บเกม (draw.thaimapgame.com)

ไฟล์ที่เว็บแสดงจริง สร้างจากโปรเจกต์ต้นฉบับด้วย `npm run build:site` — อย่าแก้ไฟล์เกมที่นี่ด้วยมือ

| ไฟล์ | คืออะไร |
|---|---|
| index.html | ตัวเกมทั้งหมด (รวมเป็นไฟล์เดียว) |
| sfx.json | เสียงอัดจริง CC0 ที่เกมใช้ (ที่มา: sfx/CREDITS.md) |
| lex.json | คลังคำ |
| lib/ | รูปศัตรูและฉากพื้นหลัง |
| sfx/ | คลังเสียงต้นฉบับ + เครดิต |
| old-data/ | ข้อมูลจากเกมเก่าที่เก็บไว้ |
| CNAME | โดเมน |

The game the site serves, built from the source project. The old draw-and-fight game: tag `old-draw-fight-final`.
