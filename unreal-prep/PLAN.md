## ระยะที่ 1 — เล่นได้จริง (ทำต่อทันที)

1. **คอมไพล์โค้ดเกม** — ปิด Editor → เปิด DrawFight จาก Epic → กด Yes ให้ rebuild → ถ้าพัง Opus อ่าน `Saved/Logs` แล้วแก้ (ผู้ใช้กด Yes, Opus แก้โค้ด)
2. **นำเข้า CSV** 11 ไฟล์ไปที่ `/Game/DrawFight/Data/` ชื่อ asset ต้องตรงชื่อไฟล์ (โค้ดโหลดจาก path นี้): Characters, Skills, WeaponClasses, Elements, Auras, SecretClasses + ที่เหลือ (ดู `MENU_SETUP.md`)
3. **ฟอนต์ไทย** — import Bai Jamjuree / Noto Sans Thai แล้วตั้ง `ThaiFont` ถ้าตัวหนังสือเป็นกล่อง
4. **ฉาก MainMenu** — เลเวลว่าง + GameMode Override = `DFMenuGameMode` + ตั้งเป็น Default Map
5. **ฉากอารีนา** — สนามกลมรัศมี 22 ม. กลางคืน GameMode ลูกของ `DFArenaGameMode`
6. **ตัวละครผู้เล่น (ยังไม่มีโค้ด)** — Character + กล้อง + `DFCombatComponent` + `DFAutoPilotComponent` · WASD เดิน, เมาส์หมุนกล้อง, คลิก/J ตี, Shift หลบ, 1-2-3 สกิล, R ท่าไม้ตาย, T ออโต้
7. **ศัตรู** — Character ลูก ใส่ 2 คอมโพเนนต์เดียวกัน ตั้งเป็น `EnemyClass`
8. **วงแดงเตือนบนพื้น** ตอน `OnWindUp`
9. **ทดสอบเล่น** เมนู → เลือกตัว → สู้ 3 ด่าน → ได้ทอง/การ์ด → หมุนออร่า → เซฟยังอยู่หลังปิดเกม

ใครทำ: Opus (คุมหน้าจอ Unreal + เขียนไฟล์ในโปรเจกต์ได้แล้ว) · ผู้ใช้: กดอนุญาต, กด Yes ตอน rebuild, ลองเล่น

## ระยะที่ 2 — สกิลอลังการ

- **ตัวรันสกิล** อ่าน `.dfskill` / DataTable → เล่นท่า → Niagara → ดาเมจตามจังหวะ (งาน Fable F1)
- ชุดแรก 11 สกิล: `slam, wave, meteor, shadow, quake, vortex, sun, thunder, rift, tornado, pause`
- **ท่าไม้ตายอาชีพลับ 9 ท่า** (`ult_*` ใน DT_Skills, Rarity = Signature ไม่ดรอปจากการ์ด)
- ตัวเลขคูลดาวน์บนช่องสกิลใน HUD + เรียกเสียงพากย์ `Skill` / `Ultimate`
- การ์ดสกิล: ภาพจากเอฟเฟกต์จริง (Scene Capture) + กรอบตามความหายาก

### กฎเอฟเฟกต์ (สกิลห้ามหน้าเหมือนกัน — บทเรียนจากเว็บ)
1. ทุกสกิลมี "ของเด่น" 1 อย่างที่สกิลอื่นไม่มี (`Signature` ใน `skill_vfx_briefs.csv` ไม่ซ้ำ 33 ตัว)
2. ชิ้นส่วนกลาง (Trail, Sparks, Smoke, Debris, Flash, Crack, Motes, Telegraph) ใช้ได้แต่เป็นตัวรอง
3. วงเวทใช้ได้ไม่เกิน 3 สกิล (meteor, sun, pause) คนละลาย
4. สีไม่ซ้ำสกิลข้างเคียง ละอองมีรูปทรงตามธาตุ
5. กล้องและเสียงช่วยแยก (หยุดภาพ, สโลว์, ซูม, สีจาง)
6. ถ่ายทุกสกิลตอนพีคเรียงกัน ปิดชื่อแล้วต้องแยกออก

## ระยะที่ 3 — ตัวละคร + ออร่า

## ระยะที่ 5 — เล่นยาว + เตรียมขาย

**เนื้อหาเล่นยาว**
- **หน้าวาดอาวุธ 2D → 3D** (ลายเส้นถูกดึงหนาเป็นโมเดล) — จุดขายหลักของชื่อเกม ต้องมีก่อนเดโม

- **คอมโบลับ ออร่า + อาชีพ** (เช่น จอมมาร + ราชาปีศาจ = ราชันนรก) ไม่บอกในเกม
- **หลอมออร่าซ้ำ** เป็นยาโชค/อัปเกรด
- **สมุดภาพสะสม + ฉายา**
- ระบบสอนเล่น 1 นาที

**เตรียมขาย**
- ตั้งค่า: กราฟิก 3 ระดับ (เป้า 1080p 60fps บน RX 6600), เสียง, ลดแสงวาบ/สั่นจอ, จอยเกม, ไทย/อังกฤษ

- **ปุ่มอัดคลิปอัตโนมัติ** (ได้ออร่าหายาก/ชนะเฉียดตาย → คลิปแนวตั้ง 15 วิ)
- **โหมดสตรีมเมอร์** คนดูไลฟ์ส่งของขวัญเรียกบอส/เพิ่มโชค (ต่อยอดจากระบบ TikTok LIVE เดิม)
- หน้าร้านตาม `STEAM_PAGE.md`, เปิด Coming Soon ≥ 2 สัปดาห์, **เดโมเข้า Steam Next Fest**
- Steamworks 100 USD

**ยังไม่ทำ:** ออนไลน์ PvP / Co-op (ต้องมีเซิร์ฟเวอร์ ไว้หลังขายได้)
