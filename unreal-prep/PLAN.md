# วาดแล้วสู้ — แผนย้ายไป Unreal Engine 5

เป้าหมาย: เกมต่อสู้ 3 มิติขายบน Steam (PC อย่างเดียว) ตัวละครเป็นอะไรก็ได้ เลือกตัวสำเร็จรูปหรือนำเข้าโมเดลเอง สกิลอลังการระดับ Unreal และผู้เล่นทำสกิลกับตัวละครมาลงเกมได้เอง

ข้อมูลทั้งหมดจากเกม 2 มิติ (สกิล 33, ธาตุ 14, อาวุธ 16, เพิร์ก 12, ศัตรู, บอส, กาชา) ดึงออกมาแล้วในโฟลเดอร์ `data/` พร้อมนำเข้า Unreal

## ระยะที่ 1 — โครงเกมเล่นได้ (เป้า: เดิน ตี ใช้สกิล 1 ตัว)

1. สร้างโปรเจกต์ C++ ชื่อ `DrawFight` จากเทมเพลต Third Person (UE 5.8) ไว้ที่ `D:\unreal\DrawFight` (ห้ามชื่อโฟลเดอร์ภาษาไทย) ต้องลง Visual Studio 2022 พร้อม "Game development with C++" ก่อน
2. คัดลอก `Source/DrawFight/*` เข้าโปรเจกต์ รวม `Build.cs` แล้วคอมไพล์ให้ผ่าน
3. นำเข้า CSV ทั้ง 9 ไฟล์เป็น DataTable คู่กับ struct ที่ตรงกัน (ชื่อไฟล์ `DT_*.csv` ↔ `FDF*Row`)
4. ทดสอบ `DFSkillPack` อ่านไฟล์ทั้ง 37 ใน `data/skills/` แล้วเทียบพลังกับ `expected.json`
5. ฉากสนามกลม รัศมี 22 เมตร แบบฉากกลางคืน (ตามตัวทดลองเว็บ) ตั้ง GameMode เป็น `DFArenaGameMode`
6. ตัวละครหลักใช้ Mannequin ไปก่อน ใส่ `DFCombatComponent` + `DFAutoPilotComponent` ผูกปุ่ม: J/คลิก = `TryAttack`, Shift = `TryDash`, T = ออโต้
7. ศัตรู: Blueprint ลูกของ Character ใส่สองคอมโพเนนต์เดียวกัน ตั้งเป็น `EnemyClass` ของ GameMode
8. ผูก event `OnWindUp` ให้แสดงวงแดงบนพื้น, `OnDamaged`/`OnHealed` ให้แสดงตัวเลขลอย (ตัวเลขอย่างเดียว ตามเกมเดิม)

ใครทำ: Opus ทั้งหมด (ผู้ใช้ต้องกดติดตั้ง Visual Studio และเปิดแอป Claude ค้างไว้)

## กฎเอฟเฟกต์: ทุกสกิลต้องไม่หน้าเหมือนกัน

บทเรียนจากตัวทดลองเว็บ: ใช้วงเวทลายเดียวกับละอองแบบเดียวกันเกือบทุกสกิล ผลคือ 37 สกิลดูคล้ายกันหมด ใน Unreal ใช้กฎนี้

1. **ทุกสกิลมี "ของเด่น" ของตัวเอง 1 อย่าง** ที่สกิลอื่นไม่มี (คอลัมน์ `Signature` ใน `skill_vfx_briefs.csv` ไม่ซ้ำกันทั้ง 33 ตัว เช่น คลื่นดาบ = รอยฟันพระจันทร์เสี้ยว, อัสนีบาต = สายฟ้าแตกกิ่ง, ทอร์นาโด = ตัวพายุหมุนจริง)
2. **ชิ้นส่วนกลางใช้ร่วมได้ แต่เป็นตัวรอง** ไลบรารีกลาง: Trail, Sparks, Smoke, Debris, Flash, Crack decal, Motes, Telegraph (dot / line / circle)
3. **วงเวทใช้ได้ไม่เกิน 3 สกิล** (meteor, sun, pause) และต้องคนละลาย: อาร์เคน, รูน, เทคโนโลยี
4. **สีไม่ซ้ำกันในสกิลข้างเคียง** ตามคอลัมน์ `Palette` — ละอองต้องมีรูปทรงตามธาตุ (เปลวไฟ, เกล็ดน้ำแข็ง, ใบไม้, หมึก) ไม่ใช่จุดกลมอย่างเดียว
5. **กล้องและเสียงช่วยแยก** ตามคอลัมน์ `Camera` และ `Sound` เช่น หยุดภาพสั้น ๆ, สโลว์โมชั่น, ซูมเข้า, สีจางทั้งจอ
6. **ทดสอบด้วยภาพเรียงกัน** ถ่ายทุกสกิลตอนพีคใส่ตารางเดียว ถ้าปิดชื่อแล้วยังแยกไม่ออกว่าตัวไหน แปลว่ายังไม่ผ่าน

## ระยะที่ 2 — สกิลอลังการชุดแรก (11 สกิล ลำดับ 1 ใน `skill_vfx_briefs.csv`)

`slam, wave, meteor, shadow, quake, vortex, sun, thunder, rift, tornado, pause`

- ระบบสกิลกลาง: อ่าน DataTable → เล่น AnimMontage → เรียก Niagara → ทำดาเมจตามจังหวะ (Anim Notify)
- เอฟเฟกต์ใช้ Niagara + Bloom + แสงจากสกิลส่องพื้น + กล้องสั่น + วงเวทเตือนบนพื้นก่อนโดน
- การ์ดสกิล: ภาพการ์ดถ่ายจากเอฟเฟกต์จริงในเกม (Scene Capture) แล้วใส่กรอบตามความหายาก

ใครทำ: **Fable** ทำตัวรันสกิล (F1) + เอฟเฟกต์แม่แบบ meteor, thunder (F2) จากนั้น Opus ทำตัวที่เหลือตามแม่แบบ

## ระยะที่ 3 — ตัวละครสำเร็จรูป + นำเข้าโมเดล

- ตัวสำเร็จรูป 6–8 ตัว (นักดาบ, นักเวท, หมาคาบดาบ, ดวงอาทิตย์, ต้นไม้, สไลม์, ลิช) พร้อมกระดูกและท่าทาง
- นำเข้า `.glb` จาก Blender/Meshy ตอนเกมรันอยู่ ด้วยปลั๊กอิน **glTFRuntime**
- ใส่กระดูกอัตโนมัติให้โมเดลที่ไม่มีกระดูก (ใช้วิธีเดียวกับตัวทดลองเว็บ: 17 กระดูก + น้ำหนักผิว) แล้วรีทาร์เก็ตท่าทางของ Mannequin ด้วย IK Retargeter
- ตรวจจับอาวุธจากโมเดลเอง (ชิ้นที่แยกจากตัว) เหมือนหนังสือเวทของลิช

ใครทำ: **Fable** (ส่วนใส่กระดูกอัตโนมัติและรีทาร์เก็ตยากที่สุดในโปรเจกต์)

## ระยะที่ 4 — ระบบม็อด (ผู้เล่นใส่สกิลกับตัวละครเอง)

- ช่องทาง A: ไฟล์ `.glb` จาก Blender → นำเข้าในเกมได้ทันที (จากระยะที่ 3)
- ช่องทาง B: สกิลจาก Unreal → แจก "ชุดทำม็อด" ให้ผู้เล่นทำใน Unreal Editor แล้วแพ็กเป็น `.pak` (Content-Only Plugin) วางในโฟลเดอร์ `Mods/` หรือผ่าน mod.io
- ช่องทาง C: ไฟล์สกิลแบบข้อมูล `.dfskill` (ตามตัวทดลองเว็บ) ใช้ชิ้นเอฟเฟกต์ที่มีในเกมมาประกอบ ไม่ต้องมี Unreal
- เกมคิดพลังรวมแล้วปรับคูลดาวน์ให้เอง (สูตรเดียวกับตัวทดลองเว็บ)

ใครทำ: Opus ทั้งหมด (ช่องทาง C ใช้ `DFSkillPack` ที่เขียนแล้ว) แจกผ่าน Steam Workshop

## ระยะที่ 5 — ระบบเกมเดิม + เตรียมขาย

## สิ่งที่ควรเพิ่ม (ยังไม่อยู่ในแผนเดิม)

**สำคัญมาก**
- **Steam Workshop แทน mod.io** เกมขายบน Steam อย่างเดียว ให้ผู้เล่นแชร์ไฟล์สกิล `.dfskill` และตัวละคร `.glb` ผ่าน Workshop กดติดตามแล้วโหลดเข้าเกมเอง ไม่ต้องตั้งเซิร์ฟเวอร์เอง Workshop มีระบบรายงานเนื้อหาและแจ้งลบตามลิขสิทธิ์ของ Valve อยู่แล้ว
- **ความยุติธรรมใน PvP** สกิลที่ผู้เล่นทำเองเปิดได้เต็มที่ในโหมดบอทและเนื้อเรื่อง แต่ในโหมดแข่งจัดอันดับต้องใช้งบพลังจำกัด (เช่น พลังรวมไม่เกินค่าที่กำหนด) และให้ฝั่งเซิร์ฟเวอร์ตรวจไฟล์ก่อนเริ่ม ไม่งั้นจะมีคนทำสกิลดาเมจ 999
- **เหตุผลให้เล่นยาว** ตอนนี้มีแค่สู้ 3 รอบ ต้องมีวงจรหลัก: สู้ → ได้เหรียญ/วัตถุดิบ → กาชาสกิล/อัปเลเวล → ด่านยากขึ้น (ย้ายดันเจียน โหมดฝูง และเนื้อเรื่องจากเกม 2 มิติมา)
- **บันทึกเกม** ตัวละคร สกิลที่มี เหรียญ ความคืบหน้า (Unreal SaveGame + Steam Cloud)

**ควรมีก่อนวางขาย**
- จอยและ Steam Deck (ต้องเล่นได้ไม่ต้องใช้คีย์บอร์ด)
- ตั้งค่ากราฟิก 3 ระดับ เป้าหมายขั้นต่ำ: 1080p 60fps บนการ์ดระดับ RX 6600 (เครื่องของผู้พัฒนาเอง ใช้ทดสอบได้ทันที)
- ตัวเลือกลดเอฟเฟกต์ สั่นจอ แสงวาบ (เกม 2 มิติมีระบบ "ความสบายตา" อยู่แล้ว ย้ายมา)
- ภาษาไทย/อังกฤษ (ตารางมีครบแล้ว)
- Steam Achievements, หน้าร้าน, ตัวอย่างเกม, เดโมสำหรับงาน Steam Next Fest
- โหมดถ่ายรูป/อัดคลิปสกิล ไว้ให้ผู้เล่นอวดสกิลที่ทำเอง = โฆษณาฟรี

**ตัดสินใจเรื่องเงิน**
- แนะนำขายตัวเกมครั้งเดียว และกาชาใช้เหรียญในเกมอย่างเดียว ผู้เล่นบน Steam ไม่ชอบกาชาเติมเงินในเกมที่ซื้อมาแล้ว
